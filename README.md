# 无损视频旋转（Android）

面向尼康相机竖拍 MOV 的安卓批量方向修正工具，也支持标准 MP4。应用只修改 MOV/MP4 视频轨道的显示矩阵，不解码或重新编码画面，因此不会降低画质，也不会改变 HEVC、PCM 音频和相机元数据。

## v1.2.0 使用方法

1. 首次启动允许读取视频，首页会按修改时间从新到旧显示 MOV/MP4 缩略图。
2. 点击首页的“筛选”，在底部抽屉中设置视频库/文件夹来源、全部/MOV/MP4格式、最新/最早/名称排序、输出位置和90°/180°/270°旋转角度。点“完成”才会应用，取消或滑动关闭不会改动当前设置。
3. 在缩略图网格中单选、多选、全选或清空；全选只影响当前筛选结果。Android 14+ 也可只授权部分视频。授权照片访问后，会隐藏与同名照片配套的短视频片段，避免把动态照片当作普通视频。
4. 默认分别输出到每个原视频目录下的 `rotate` 子目录，也可改选统一输出目录。Android 禁止写入的顶层目录会自动转存到 `Movies/无损视频旋转/原文件夹/rotate`。
5. 点击“开始无损旋转”。任务切到后台后会通过通知显示进度并可取消。右上角齿轮可查看版本、作者、联系方式和赞赏码。

“文件夹”入口仍然保留，适用于存储卡、下载目录或没有被系统视频库收录的文件。

输出文件名示例：`DSC_4386_rot270.MOV`。应用不会覆盖或修改原片；重名时会自动增加序号。

## 兼容性说明

- 最低 Android 8.0（API 26），目标 Android 16（API 36）。
- 页面会避开状态栏、刘海区域和底部导航栏，支持竖屏、横屏与平板自适应网格。
- 支持 ISO-BMFF/QuickTime 结构的 `.MOV` 和 `.MP4`，不递归扫描子目录。
- 严格无损旋转依赖播放器遵循标准显示矩阵。少数播放器或上传平台可能忽略、移除该信息；这种情况下只有重新编码像素才能强制所有平台显示一致。
- 带有缩放、镜像、倾斜或透视显示矩阵的特殊文件会被安全跳过，不会冒险改写。

## 构建与测试

环境要求：JDK 21、Android SDK Platform 36、Build Tools 36.0.0。

```powershell
.\gradlew.bat :core-tests:test :app:assembleDebug
```

核心测试会使用仓库根目录的 `DSC_4386.MOV`（存在时），分别生成90°、180°和270°临时结果，并验证：

- 输出大小与原片相同；
- 检测到的绝对显示角度正确；
- 除标准显示矩阵字节外，文件中的其他字节全部不变。

测试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，交付文件名为 `无损视频旋转-v1.2.0-debug.apk`。
